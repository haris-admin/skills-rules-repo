# Unit Economics & Contribution Margin Reference

Unit economics describe the direct revenues and variable costs associated with a single customer, transaction, or unit of product.

---

## 1. Unit Revenue & Variable COGS

### Contribution Margin
Contribution margin measures the profit generated by a single unit that contributes toward covering fixed operating expenses (salaries, office, overhead):

$$\text{Contribution Margin} = \text{Revenue per Unit} - \text{Variable Cost per Unit}$$
$$\text{Contribution Margin \%} = \frac{\text{Contribution Margin}}{\text{Revenue per Unit}} \times 100\%$$

### Variable COGS by Project Type

| Project Archetype | Direct Variable Costs (COGS) | Fixed Operating Overhead (Excluded from COGS) |
|:---|:---|:---|
| **B2B Regulatory SaaS (e.g. AML Hive)** | ASIC register query fees, international PEP/sanctions API calls, Brevo SMS verification, Stripe payment fees (1.75% + 30c) | Core engineering salaries, AWS RDS fixed provisioned baseline, domain renewals |
| **Merchant Payments (e.g. Tapease)** | Interchange & card scheme network fees, acquiring bank processing cut, gateway API charges | POS terminal inventory (capitalized/amortized), core server ops |
| **Agent / AI OS (e.g. Simplifii-OS)** | LLM inference token API fees (Anthropic, OpenAI, OpenRouter), vector DB read/write units | Developer tooling subscriptions, base cloud instances |

## 2. Customer Acquisition Cost (CAC) & Payback Period

### Fully Loaded vs Blended CAC
- **Paid CAC**: $\frac{\text{Direct Paid Ad & Campaign Spend}}{\text{Customers Acquired via Paid Channels}}$
- **Blended CAC**: $\frac{\text{Total S\&M Spend (Ads + Sales Tools + Rep Salaries)}}{\text{Total New Customers Acquired}}$

### CAC Payback Period (Months)
The time required for an active customer to generate sufficient gross profit to recoup their acquisition cost:

$$\text{CAC Payback (Months)} = \frac{\text{CAC}}{\text{Monthly ARPU} \times \text{Gross Margin Fraction}}$$

- **Target Benchmarks**:
  - SMB / Prosumer ($10–$250/mo): **$< 6$ months**
  - Mid-Market ($250–$2,000/mo): **$< 12$ months**
  - Enterprise ($2,000+/mo): **$< 18$ months**

---

## 3. Customer Lifetime Value (LTV) & Ratio

$$\text{LTV} = \frac{\text{ARPU} \times \text{Gross Margin Fraction}}{\text{Monthly Churn Rate}}$$

$$\text{LTV / CAC Ratio} = \frac{\text{LTV}}{\text{CAC}}$$

- **$< 1.0\times$**: Value destruction. Every customer acquired loses money.
- **$1.0\times – 2.9\times$**: Fragile unit economics. Vulnerable to churn or marketing price inflation.
- **$\ge 3.0\times$**: Standard venture-viable target.
- **$> 5.0\times$**: High efficiency; business may be under-investing in top-of-funnel acquisition.

---

## 4. Break-Even Unit Volume

$$\text{Break-Even Units} = \frac{\text{Total Monthly Fixed Overhead}}{\text{Contribution Margin per Unit}}$$
