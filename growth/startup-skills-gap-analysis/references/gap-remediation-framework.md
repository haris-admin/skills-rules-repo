# Skills Gap Remediation Decision Framework

Once a competency gap is identified, founders must choose the fastest, most capital-efficient remediation path. In early-stage startups, hiring a full-time employee is often the slowest and most expensive option.

---

## 1. The 4 Remediation Pathways

```
                          STRATEGIC CORE ADVANTAGE?
                                    ▲
                                    │
               QUADRANT 1: HIRE     │    QUADRANT 2: UPSKILL / TRAIN
            Full-Time A-Player      │    Develop internal talent
            High strategic value    │    Fast learner + high context
            Long-term commitment    │    Preserves culture & momentum
                                    │
   HIGH URGENCY ────────────────────┼──────────────────── LOW URGENCY
                                    │
               QUADRANT 3: FRACTIONAL│   QUADRANT 4: AUTOMATE (AI AGENTS)
               Agency / Contractor  │   Autonomous Agent Fleet / Tools
               Specialized expert   │   Repeatable, deterministic
               Immediate execution  │   Near-zero variable headcount cost
                                    │
                                    ▼
                         NON-CORE / COMMODITY WORK
```

---

## 2. Decision Tree Criteria

### Option A: Automate with AI Agent Fleet (First Choice)
- **Criteria**: The task is deterministic, text/code-heavy, repeatable, and requires high speed (e.g., code reviews, test writing, regulatory registry searches, market intelligence scraping, first-draft copy).
- **Tooling**: Antigravity agents, Hermes fleet (Pluto, Vigil, Vulcan), Codex CLI.
- **Cost**: API compute tokens; $0 headcount burn.

### Option B: Engage Fractional / Contractor Specialist
- **Criteria**: High expertise required immediately, but insufficient workload or cashflow to justify a full-time senior salary (e.g. fractional CFO for audit prep, AML/CTF legal compliance sign-off, specialized AWS security audit).
- **Commitment**: 5–20 hours/month or 4-week sprint.
- **Advantage**: Instant senior capability with zero equity dilution or severance overhead.

### Option C: Upskill / Train Existing Team
- **Criteria**: Strategic capability where an existing engineer or founder already has 60% of the prerequisite context and strong intrinsic motivation.
- **Timeline**: 2–6 weeks of deliberate study, pair programming, and reference skills.

### Option D: Hire Full-Time (A-Player)
- **Criteria**: Core, permanent competitive advantage of the company (e.g. Founding AI Engineer, Head of B2B Sales, Product Designer).
- **Threshold**: Requires 3–6 months of verified cash runway and clear post-milestone revenue visibility.
