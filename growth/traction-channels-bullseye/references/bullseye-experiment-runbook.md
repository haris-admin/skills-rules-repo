# Bullseye Framework Experiment Runbook

The Bullseye Framework is a 3-ring method to identify the single most effective customer acquisition channel for your current startup stage.

---

## 1. The Three Rings of the Bullseye

```
             ┌────────────────────────────────────────────────────────┐
             │                OUTER RING: WHAT'S POSSIBLE             │
             │           Brainstorm tests for all 19 channels         │
             │     ┌────────────────────────────────────────────┐     │
             │     │        MIDDLE RING: WHAT'S PROBABLE        │     │
             │     │      Run cheap, fast tests on 3-5 channels │     │
             │     │     ┌────────────────────────────────┐     │     │
             │     │     │       INNER RING (BULLSEYE)    │     │     │
             │     │     │       Focus 80%+ on 1 channel  │     │     │
             │     │     └────────────────────────────────┘     │     │
             │     └────────────────────────────────────────────┘     │
             └────────────────────────────────────────────────────────┘
```

---

## 2. The 3-Step Bullseye Process

### Step 1: Outer Ring (Brainstorm What's Possible)
- Review all 19 channels with zero bias.
- For each channel, write down at least one concrete idea:
  - What would a test look like?
  - What is the estimated Customer Acquisition Cost (CAC)?
  - How many customers could this channel yield if successful?
  - What is the time commitment to run an initial test?

### Step 2: Middle Ring (Test What's Probable)
- Select the top 3–5 highest-ranked channels using the **ICE Scoring Model**:
  - **Impact (1–10)**: If this works, how much customer volume will it bring?
  - **Confidence (1–10)**: How confident are we that this test will generate signal?
  - **Ease (1–10)**: How cheap and fast is it to test ($/time)?
  $$\text{ICE Score} = \frac{\text{Impact} + \text{Confidence} + \text{Ease}}{3}$$
- Design micro-experiments designed **only to answer one question**: *Is this channel promising?*
- Budget limit: $\le \$500 – \$1,000$ or $\le 2$ weeks per experiment.

### Step 3: Inner Ring (Focus on What's Working)
- Analyze the test results from the middle ring.
- Pick the **single channel** that demonstrated the best traction metrics (lowest CAC, highest conversion, fastest velocity).
- Direct **80% or more of your marketing bandwidth and budget** into this primary channel.
- Scale and optimize this channel until diminishing returns occur (channel saturation), at which point you re-run the Bullseye loop.
