# Value Proposition Messaging & Copy Matrix

A structured translation framework moving from strategic positioning to customer-facing copy across landing pages, pitch decks, and sales collateral.

---

## The Messaging Hierarchy

```
┌─────────────────────────────────────────────────────────────┐
│ 1. THE HERO HEADLINE (The Core Transformation / Outcome)    │
│    "Stop paying $35 chargeback fees on friendly disputes."  │
├─────────────────────────────────────────────────────────────┤
│ 2. THE SUB-HEADLINE (How It Works & For Whom)               │
│    "Undispute resolves transaction conflicts with issuing   │
│     banks within 48 hours before penalties hit your account"│
├─────────────────────────────────────────────────────────────┤
│ 3. THE 3 VALUE PILLARS (Differentiated Capabilities)        │
│    • Pillar 1: Automated 48-Hour Grace Period Window        │
│    • Pillar 2: 1-Click Scheme Webhook Integration           │
│    • Pillar 3: Zero Disruption to Existing Merchant POS     │
├─────────────────────────────────────────────────────────────┤
│ 4. THE PROOF POINT / RISK REVERSAL                          │
│    "100% money-back guarantee: Pay nothing if we don't save │
│     at least 3x our subscription fee in avoided chargebacks"│
└─────────────────────────────────────────────────────────────┘
```

## Value Proposition Canvas Alignment (Strategyzer)

| Customer Profile (The Problem) | Value Map (The Solution) | Alignment Test |
| :--- | :--- | :--- |
| **Customer Jobs**: Tasks they are trying to get done (e.g. submit quarterly BAS, reconcile daily POS takings). | **Products & Services**: Your core platform, APIs, or automated features. | Does the product directly perform or automate the job? |
| **Customer Pains**: Blockers, risks, and expenses (e.g. fear of AUSTRAC penalties, bank penalty fees). | **Pain Relievers**: Specific mechanisms that eliminate or reduce those pains. | Does this eliminate the worst outcome for the buyer? |
| **Customer Gains**: Desired outcomes and aspirations (e.g. peaceful sleep, clean balance sheet, rapid growth). | **Gain Creators**: Features that produce tangible upside or unexpected delight. | Does this make the buyer look heroic to their boss or peers? |
