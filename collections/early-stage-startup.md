# Early-Stage Startup Collection

Use this collection to move from a promising observation to a defensible next decision across early-stage startup ventures (**AML Hive**, **TAPEase**, **Simplifii-OS**, **Undispute**). It is a discovery map, not a rigid sequence: start at the point matching your current uncertainty, then combine skills to reach the next proof point.

## Founder Workflow

1. **Extract and Test Assumptions.** Map Desirability, Feasibility, and Viability risks using [Startup Idea Validation](../growth/startup-idea-validation/SKILL.md). Run Mom-Test interviews to surface past customer behavior rather than hypothetical promises.
2. **Quantify the Opportunity.** Build bottom-up TAM, SAM, and SOM models with [Market Sizing TAM/SAM/SOM](../growth/market-sizing-tam-sam-som/SKILL.md). Ground revenue ceilings in verified account counts and defensible ACV.
3. **Analyze Adversaries and Moats.** Evaluate incumbent retaliation barriers ("Can't vs Won't" test) and Hamilton Helmer's 7 Powers with [Adversary Analysis Assessment](../growth/adversary-analysis-assessment/SKILL.md). Craft battlecards to defeat customer inertia and status quo spreadsheets.
4. **Define Positioning and Value.** Formulate the 5-component positioning statement and Value Proposition Canvas using [Value Prop & Positioning](../growth/value-prop-and-positioning/SKILL.md).
5. **Architect Inclusive & Behavioral UX.** For neuroinclusive platforms like Simplifii-OS, apply W3C COGA cognitive load limits with [Neuroinclusive Design Patterns](../frontend-and-ux/neuroinclusive-design-patterns/SKILL.md) and break activation inertia with [Executive Function Scaffolding](../growth/executive-function-scaffolding/SKILL.md).
6. **Maintain Company Intelligence.** Connect autonomous agent research, meeting logs, and cross-project memory via [GBrain Agent Memory](../research/gbrain-agent-memory/SKILL.md).
7. **Iterate Toward Product-Market Fit.** Measure the Sean Ellis 40% threshold and execute 50/50 optimization sprints using the [Product-Market Fit Engine](../growth/product-market-fit-engine/SKILL.md).

## Scope Boundary

This collection covers pre-build, validation, market sizing, competitive defensibility, inclusive design, dispute network mechanics, and commercial scaling. Use engineering and infrastructure deployment skills once specific architectural and operating milestones have been established.
