# Compound Engineering

## The Compounding Loop
Every task produces two outputs:
1. **Working Software** (passing tests, deployed code).
2. **Organizational Learning** (updated skills, new rules, post-mortems, prompt improvements).

## Practices
- **Post-Feature Retrospectives**: Measure task loops, drift score, and unexpected refactors.
- **Rule Codification**: When a mistake or ambiguity occurs twice, codify it into a standing rule or skill immediately.
- **Adversarial Hardening**: Review completed implementations with an adversarial posture before closing.
