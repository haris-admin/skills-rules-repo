# YouTube Channel Handle & ID Discovery

## When a YouTube handle is unknown

### Method A: Curl channel page (most reliable, not rate-limited)

```bash
# Try handle
curl -sL --max-time 10 -A "Mozilla/5.0 (X11; Linux x86_64)" \
  "https://www.youtube.com/@HANDLE" 2>/dev/null | \
  grep -oP '"channelId":"[^"]+"' | head -1 | grep -oP ':"\K[^"]+'

# Or externalId (used on some YouTube page variants)
curl -sL --max-time 10 -A "Mozilla/5.0" \
  "https://www.youtube.com/@HANDLE" 2>/dev/null | \
  grep -oP '"externalId":"[^"]+"' | head -1
```

### Method B: YouTube search results page

When the exact handle is unknown, search YouTube and grep for @handle patterns:

```bash
curl -sL --max-time 10 -A "Mozilla/5.0" \
  "https://www.youtube.com/results?search_query=PODCAST+NAME+EPISODE" 2>/dev/null | \
  grep -oP '/@[a-zA-Z0-9_-]+' | sort | uniq -c | sort -rn | head -5
```

This returns handle frequency in search results — the most frequent is usually the official channel.

### Method C: yt-dlp (may be rate-limited)

```bash
yt-dlp --flat-playlist --print "%(channel_id)s|%(channel)s" \
  "ytsearch5:Podcast Name episode" 2>/dev/null | head -3
```

Use as last resort — yt-dlp may be IP-rate-limited after transcript downloads.

## Channel Type Detection

**Standard user channels** (flat-playlist works):
- Flat-playlist returns videos with IDs
- `@handle` URL loads a page with a /videos tab
- Individual date fetches work

**Topic channels** (flat-playlist returns nothing):
- `flat-playlist` produces "This channel does not have a videos tab"
- Need channel ID URL: `https://www.youtube.com/channel/UC...`
- Content exists but is auto-generated by YouTube — limited metadata
- Examples: Masters of Scale, How I Built This (topic variants)

**Fallback for topic channels:** Use `ytsearch` with channel name filter:
```bash
yt-dlp --flat-playlist --playlist-end 30 \
  --print '%(title)s||%(id)s||%(channel)s' \
  "ytsearch30:Podcast Name full episode" | grep "Target Channel"
```
