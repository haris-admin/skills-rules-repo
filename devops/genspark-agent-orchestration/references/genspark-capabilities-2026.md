## Genspark Claw — "Your First AI Employee"
- Desktop/cloud agent that runs 24/7
- **Computer Use** — operates local files, apps, screen
- **Browser Use** — navigates web automatically
- Works via WhatsApp, Slack, Teams, Telegram, Discord, Signal, etc.
- 30+ built-in skills (research, email, docs, code, images, video, phone calls)
- Remembers context across sessions and channels
- Scheduled tasks run in background

## Genspark vs Pluto
| Dimension | Pluto (Hermes) | Gumby GC (Genspark) |
|-----------|---------------|-------------------|
| Platform | Open-source Hermes Agent, WSL | Closed-source Genspark Claw, cloud |
| Model Access | DeepSeek (current) | GPT-5, Claude, Gemini — multi-model orchestration |
| Strength | Automation pipeline, cron, data flow | Research depth, slide/image creation, fact-checking |
| Limitation | Single model, no visual output | 10K credit cap, running on Genspark infra |
| Role | Primary orchestrator + daily pipeline | Research assistant + creative output |
