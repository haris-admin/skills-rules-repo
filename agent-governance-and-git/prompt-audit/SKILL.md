# Prompt Quality Audit

## Diagnostics
1. **Correction Rate**: Frequency of "No, that's not what I meant" turns.
2. **Task Loop Rate**: Number of attempts before a unit test passes.
3. **Rule Suggestions**: Codify recurring corrections into persistent agent rules to prevent repeat friction.
