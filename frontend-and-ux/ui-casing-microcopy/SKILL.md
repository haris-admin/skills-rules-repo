# UI Casing & Microcopy Standards

## Conventions
1. **No Screaming Uppercase**: Never render unmapped enum strings directly (e.g. `ALERT_SENT` → format as `Alert Sent`).
2. **Page & Section Headings**: Use Title Case or clean Sentence Case consistently.
3. **Buttons & Actions**: Use Title Case or Sentence Case; avoid raw CSS `text-transform: uppercase`.
4. **Professional Microcopy**: Use concise, executive phrasing (e.g., `Priority Action Items` instead of `Reach 80% — what's needed?`).
